# 🗳️ Online Polling System

An online polling system that allows users to participate in polls and submit their choices through a simple digital interface.

## 📌 Project Overview

The Online Polling System is designed to provide a simple and convenient way to conduct polls digitally.

The system allows users to view available polling questions, select an option, and submit their response. The collected responses can be used to display the polling results.

## 🎯 Objectives

- Provide an easy-to-use online polling interface.
- Allow users to participate in polls.
- Record user responses.
- Display polling results.
- Reduce the need for manual polling.
- Provide a simple and user-friendly system.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask
- SQLite

## ⚙️ How the System Works

```text
User
  ↓
Open Polling System
  ↓
View Poll Question
  ↓
Select an Option
  ↓
Submit Vote
  ↓
Store Response
  ↓
Display Poll Results
```
```

## ✨ Features

## 📱 Application Flow

1. The user opens the polling system.
2. Available poll questions are displayed.
3. The user selects an option.
4. The user submits the vote.
5. The response is stored.
6. The polling results are displayed.
